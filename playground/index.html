Scenario 1 — Boolean attribute removal

A button starts disabled via a template expression. Clicking "Toggle" should remove the disabled attribute on the next render. Regression test for the __patchUnequalAttributes fix.

Scenario 2 — Empty string slot ${condition ? '<el>' : ''}

A template expression produces an empty string on the falsy branch. Toggling the condition should show/hide the element without breaking subsequent renders. Repro for issue #8.

Scenario 3 — Variable-count ${list.map(…).join('')}

A list rendered inline with .map().join('') starts with 2 items. Clicking "Add item" should grow it to 3, then 4, etc. Repro for issue #12 — the reconciler silently drops new items when count increases.

Scenario 4 — on-load for cached / data-URI images

An <img> with a data: URI is always complete synchronously (el.complete === true) before the on-load handler is attached. The handler should still fire via the synthetic-event fix. Regression test for issue #11.
